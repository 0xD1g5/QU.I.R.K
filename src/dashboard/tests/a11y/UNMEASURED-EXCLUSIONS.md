# Unmeasured exclusions (Phase 221, D-12)

Every place the dashboard a11y harness does NOT measure is a named row here. Unlike the
generated `ACCEPTED-VIOLATIONS.md`, this file is HAND-maintained, and it is enforced by
`unmeasured-exclusions.test.ts`, which derives the REQUIRED row set from source at run time
(`App.tsx` routes, `routes.json`, `FIXTURE_HANDLERS`). A swept page cannot keep a stale row, and a
newly un-swept page or retired leg cannot be omitted: the test names the missing or orphaned
`Key`. A blind spot must never pass implicitly.

The 216 W1 probe nodes are deliberately NOT a row: 221-01 repaired them (see
`harness-falsification-probe.test.ts`, Injection D).

Owner `999.118` is the `.planning/HORIZON.md` ledger row that carries these forward.
