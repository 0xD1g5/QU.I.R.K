# Adopt the PQC brand identity (docs/brand/) across every product surface

The new identity is a lens-as-Q logo with six post-quantum easter eggs. It lives in `docs/brand/`, and
its rules are in `docs/brand/BRAND-GUIDELINES.md`. Nothing in the product uses it yet. Today's branding
is an electric-blue (`#3b9dff`) "Q" favicon and a monospace text wordmark in the dashboard sidebar.
This todo covers swapping every surface over **without breaking the tests and UAT criteria that pin
the old branding**.

## Raster pipeline (blocker for favicon.png / .ico / social preview)

The generator is stdlib-only and emits SVG. Raster exports need a renderer. Options:
1. Playwright/Chromium screenshot script (`scripts/`). Chromium is already used in CI-adjacent tooling.
2. `cairosvg` as a dev-only dependency (do **not** add it to any runtime extra).
3. Commit the PNG/ICO outputs and regenerate by hand.
Pick one. Add a check that the committed rasters match the current SVGs (or document that they are
manual), so they can't drift silently.
