## READ THIS BEFORE RESUMING A PAUSED PHASE

**`/gsd-autonomous --from N --to N` IS UNSAFE for a phase that is mid-execution.** The previous
handoff recommended exactly that for Phase 206. It was not followed, and here is why:

- The autonomous workflow's **plan step has no `has_plans` gate** — it calls `gsd-plan-phase`
  unconditionally and only checks `has_plans` *afterwards*.
- `gsd-plan-phase` itself only guards against replanning **CLOSED** phases (VERIFICATION status
  `passed`). A *paused* phase is not closed, so the guard never fires.
- Phase 206 had 13 plans written and 5 executed. The planner would have run over them — including
  `206-13`, the disposition fence the whole phase was sequenced around.

**Use instead:** `Skill(gsd-execute-phase, "<N> --no-transition")`. Its workflow filters
`Skip plans where has_summary: true` (line 321), so it resumes correctly — it ran exactly the 8
incomplete plans. Note the asymmetry worth reporting upstream: the *discuss* step DOES skip on
`has_context`; only *plan* lacks the matching gate.

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| A hand-assembled list drifts — including one assembled by whoever is warning others not to | The orchestrator briefed plan 13 that there were **6** partial conversions. Plan 12 was scheduled to file a todo for it. Caught only by re-running D-A2's own four commands. | blocking | Re-run a decision's own evidence commands before acting on it. Never act on a recorded conclusion whose check you have not repeated. |
| A suggested mutation turns something ELSE red | Three plans' proposed red-proof mutations were inadequate. 206-04 needed **three** attempts before one failed at the intersection assertion it was meant to prove; 206-08 found the plan's mutation left a data-only assertion green because the product keys colour off *style selectors* while the datum survives. | blocking | Verify the mutation makes YOUR named assertion fail at ITS named line.
