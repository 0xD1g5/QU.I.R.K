- [ ] **CONSTRAINT: exit code is not evidence.** Three defects found today all exited 0 — a
      stale prober reporting **91/100** under superseded scoring v2; download routes serving
      the wrong directory with **HTTP 200 on every format**; a scan writing eleven artifacts
      with **no PDF and no warning**. Each was a confident success hiding a wrong outcome, the
      same shape as the crown-jewel ring that rendered black for months while API, tests and
      bundle were all green. **Structural mitigation:** assert the observable outcome — a
      launched browser, `%PDF` magic bytes, an HTTP 200 carrying a non-empty body of the right
      type. `scripts/validate-fresh-install.sh` is built entirely on this.

- [ ] **CONSTRAINT: a count produced by the audited tool is not a measurement.** The doc audit
      produced **six** findings that dissolved under a second method, including a reported
      **"76 undocumented config fields"** that was purely an extractor artifact, plus `5.5.7`
      (an OID fragment), `5.3.1` (a section number), and `quirk hardware` (whose hits were
      *negative* references saying the command does not exist). **Structural mitigation:**
      re-derive every count with an independent method before recording it. Disagreement
      between the two IS the finding.

- [ ] **CONSTRAINT: a self-check that exercises only the skip path proves nothing.**
      `validate-fresh-install.sh --self-check` passed while skipping all nine checks.
      **Structural mitigation:** mutation-test the guard — break the thing it watches and
      confirm it goes red. Done for the install harness and the master-guide fence tracker
      (breaking the tracker kills 4 of 11 tests; restoring brings all 11 back).

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Green-means-working | Graceful degradation designed for "dependency absent" silently absorbed "dependency present but unlaunchable". `render_pdf_report()` caught the error, returned `False`, and the scan exited 0. | blocking | Assert the artifact exists and is valid, not that the command succeeded |
| Grep measures notation, not meaning | A doc audit by grep finds strings, not claims — 6 of 15 candidate findings were artifacts | blocking | Second independent method before recording any finding |
| Verification commands that lie | `$?` through a pipe captured `tail`; a lingering `cd` produced 127; **zsh does not word-split unquoted parameters**, so `pytest $sel` passed 53 paths as one argument and ran **zero** tests while printing "2 warnings in 0.00s" | advisory | Use `${=sel}`; confirm an `N passed` count, never just absence of errors |
| Hand-merged derived documents | A merged copy is stale the moment a source is edited, producing two contradictory descriptions of the same behaviour | advisory | Generate it; the master can lag its sources but cannot disagree with them |
