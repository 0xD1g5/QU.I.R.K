# BLOCKING CONSTRAINTS — Read Before Anything Else

> Each was discovered through actual failure this session, not predicted.

- [ ] **CONSTRAINT: verify `SCORING_VERSION` INSIDE the prober before quoting any score.**
      `lab.sh up` passes no `--build`, so a stale `chaoslab-mh-prober` image is reused silently.
      That made a scan report **91/100** from the superseded scoring v2 while `main` was on v3 —
      the same evidence scores **15/100**. Exit 0, eleven report files, a confident number, no
      warning. `Platform version` is NOT a staleness signal (pyproject has not bumped since the
      PyPI release). **Structural mitigation:**
      `docker exec chaoslab-mh-prober-1 python -c "from quirk.intelligence.scoring import SCORING_VERSION; print(SCORING_VERSION)"`
      — and rebuild with **`-p chaoslab`** or compose tags a different image
      (`quantum-chaos-enterprise-lab-mh-prober`), reports "Built", and changes nothing.

- [ ] **CONSTRAINT: a green API + green unit tests + a correct bundle can all coexist with a
      visibly broken UI.** The crown-jewel ring rendered **black** for months. The data was right,
      the border was applied at the right width, every test passed — the colour was simply wrong,
      because Cytoscape draws to `<canvas>` with its own parser and cannot read the modern
      space-separated `hsl()` syntax that `--accent`'s raw components produce. **Structural
      mitigation:** for any *visual* claim, look at rendered pixels. `renderedStyle()` in the live
      page is the check; a passing test is not.

- [ ] **CONSTRAINT: the CLI and the dashboard disagree on the SAME clean scan — do not show both.**
      Report 15/100 with 5 CRITICAL; dashboard 19/100 with 7 CRITICAL. Option B (`819f31da`) fixed
      the wrong *title* but the gap is **architectural**: `quirk/engine/findings_evaluator.py` has
      **zero** SAML/Kerberos/DNSSEC rules while `quirk/dashboard/api/routes/scan.py` has all three,
      and the two name the same condition differently (`Plaintext HTTP service detected` vs
      `Unencrypted HTTP service`). Separately, `SESSION_BRACKET = 5 min` merges scans taken under
      five minutes apart — and the scan is **19 seconds**, so this is easy to trigger by accident.
      **Scan once.**

- [x] **CONSTRAINT (DISCHARGED): do not hand-write an expected finding for a host you have not
      measured.** Closed 2026-09-14 by measurement and by a committed generator
      (`quantum-chaos-enterprise-lab/scripts/gen_multihost_oracle_table.py`), so it is now
      structurally enforced rather than remembered. It earned its keep: two of the previous ten
      hand-written oracle rows had the severity COUNT right and the MEANING wrong.
      **Regenerate, never hand-edit.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Trusting a green test as a claim about the rendered product | The crown-jewel ring was black in every render since Phase 195. 195-06 logged it as an honest GAP ("no live data exercises either path") so it shipped never having rendered once. | **blocking** | For any visual claim, inspect the live page. Data-level and unit-level checks cannot see a valid property holding a wrong value. |
| A hand-derived list of sites standing in for a source scan | My own "4 rollup render sites" list was wrong — there were 5 (html_renderer imports the helper without matching the string I grepped). | **blocking** | Enumerate from the import graph or the AST, never from a remembered list. `grep -rn "<helper>(" quirk/` before editing N sites. |
| Changing a SHARED derivation to fix ONE consumer | `compute_key_reuse_clusters` is shared with the report surface, where cross-scan is DELIBERATE (D-03). Scoping it unconditionally would have silently changed every report. | **blocking** | Enumerate callers first. Make the new behaviour opt-in and pin the old default with a test. |
| Reading an exit code instead of the result | A background watcher exited 0 while Python CI had FAILED, and was watching the wrong SHA. | **blocking** | Read the actual check table / failing-node list. Never infer CI state from a wrapper's status. |
| Comparing failing COUNTS instead of SETS | Counts move with Docker health and skip collection; only the node SET is meaningful. | advisory | Capture the failing SET and compare against the base branch's own CI run. |
| `pytest -k "scor"` as the scoring check | 12 of 36 files importing `quirk.intelligence.scoring` have no "scor" in the path. | advisory | `$(grep -rln "quirk.intelligence.scoring" tests/)` — ran green at 449 passed / 3 xfailed. |
| The workflow's own placeholder grep false-positives | `grep -l "To be filled\|placeholder\|TBD"` matched 7 phase docs; 5 were prose ASSERTING the absence of placeholders, quoting the grep itself, or naming a UI "owner placeholder" feature. | advisory | Open each hit. Re-verified at this pause: **no false completions.** The 2 real hits are `205-05-PLAN.md` citing a `Plans: TBD` line it exists to fix, and `206-VALIDATION.md`'s honest in-progress rows (206 is paused at 5/13 by design). |
| A guard that fires on its own documentation | The first version of `exposure-map-colors.test.ts` failed on the COMMENT describing the bad pattern. | advisory | Strip comments before scanning source. A guard that fires on its own prose trains people to ignore it. |
| A cached `index.html` serving a stale bundle | The ring looked still-broken after it was fixed, because the browser held the old JS. | advisory | **Hard-refresh (⌘⇧R)** after any dashboard change — a normal reload is not enough. |
