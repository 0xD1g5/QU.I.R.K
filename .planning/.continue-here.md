## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| pytest truncates assertion lists | `test_config_connector_drift` printed **1** undeclared key when there were **11**. Grepping the failure output produced a confident wrong number; calling the gate's own `_divergent_connector_keys(...)` produced the real set. A follow-up fix then declared 10 of 11 and missed one. | blocking | Never derive a set from a pytest failure message. Call the gate's own computation and diff set-difference both directions until empty. |
| Confirming the predicted field, ignoring the rest of your own output | A `pip install --dry-run --report` that had already been run and quoted contained `cryptography -> 46.0.7`. Only `sslyze` and `nassl` were checked, so a dependency cap shipped undocumented until an operator's pip output forced a re-read. | blocking | Read the whole artifact you generated, not the field you went looking for. Treat any truncation (`...`, `+N more`, collapsed diff) as a signal to recompute. |
| Parsed values are not the file's bytes | `yaml.safe_load` reported `ports_tls: [443, 80, ...]`; a string replacement written against that pretty-printed form failed because the file had no spaces after commas. | advisory | When editing text from parsed data, assert the literal `old` string is present (count == 1) before replacing. The assertion is doing real work. |
| `readlink -f /proc/<pid>/exe` defeats venv detection | It resolved a venv's `bin/python` symlink to `/usr/bin/python3.14`, so a diagnostic ran outside the venv and reported `ModuleNotFoundError` for a package that WAS installed. | advisory | For environment-sensitive checks read `/proc/<pid>/cmdline` (argv[0]), not `exe`. `sys.prefix` derives from argv[0]. |
| Docker Desktop on Apple Silicon masks amd64-only images | `kenchan0130/simplesamlphp:1.19.7` is amd64-only; it has run 33+ hours on the Mac under silent emulation and died with `exec format error` on a clean aarch64 VM. An earlier "all images are arm64" check measured the Mac and missed it. | advisory | Check `docker inspect <image> --format '{{.Architecture}}'` per image, not `uname -m` inside a running container on an emulating host. |
