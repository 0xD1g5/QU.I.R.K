# LEDGER.md — the master ledger of every open item

**Established:** 2026-11-06 (operator decision). Supersedes the Open-Item Ledger that lived in
`.planning/HORIZON.md`; that section's last text is archived at
`.planning/archive/HORIZON-open-item-ledger-2026-11-06.md`.

## Rules

1. **Everything is added here first.** Every bug, feature, idea, audit finding, review finding
   and human-UAT leftover gets a row in this file when it is found. A todo file under
   `.planning/todos/pending/` or a backlog folder under `.planning/backlog/` is optional
   supporting detail; it is never a second home.
2. **Never delete a row.** Close it by changing its Status and citing evidence. Reopen it the
   same way.
3. **`DONE` needs evidence on `main`**: a commit that `git merge-base --is-ancestor <sha> main`
   accepts, or a `file:line` on main showing the fixed behaviour. A doc saying "CLOSED" is not
   evidence; several rows below were marked shipped for months while the fix sat on a branch.
4. **When a todo's row closes, move the todo** to `.planning/todos/completed/` with a
   `## Resolution` section.
5. **Embargoed security items are never listed here.** This file is tracked in a public repo.
   They live only in `.planning/security-embargo/` (untracked), including its
   `LEDGER-PRIVATE.md`. A row whose detail is already public uses a generic title.
6. **Development tooling is tracked, but kept apart.** Open or deferred rows about the GSD
   toolchain (area `gsd-tooling`) or this machine's dev environment (area `dev-env`) live in
   § Development tooling (not shipped), never in § Open, and are not counted in the product's
   priorities.

## Columns

| Column | Values |
|---|---|
| ID | New item: `YYMMDD-short-slug` (the same shape as a todo stem, so a todo file can be added later under that name). Legacy: `999.N` backlog item, `BACK-N` legacy backlog, todo filename stem, `A0508:`/`A0527:` audit finding, `HUAT:<phase>` human-verification leftover |
| Status | `OPEN`, `DEFERRED` (recorded decision to push later), `DONE`, `DUPLICATE` (Evidence names the canonical ID), `OBSOLETE` (no longer applies) |
| Priority | `P0` release-blocking · `P1` high · `P2` medium · `P3` low / someday |
