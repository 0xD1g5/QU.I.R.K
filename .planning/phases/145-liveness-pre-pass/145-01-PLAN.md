<objective>
Build the two backend primitives the liveness pre-pass needs, both as sibling functions to existing
code in the same files: a host-status XML parser that surfaces down hosts (which
`parse_nmap_xml()` structurally cannot), and an nmap `-sn -PS<ports>` liveness probe runner.

Purpose: DISC-03's pre-pass cannot skip non-responsive hosts (or record them per D-04) without a
way to (a) run a cheap TCP-SYN/ACK probe and (b) read per-host up/down state out of its XML.
Neither exists in the codebase today.
Output: `NmapHostStatus` + `parse_nmap_host_status()` in `nmap_parser.py`;
`_liveness_nmap_args()` + `_resolve_liveness_port_spec()` + `run_nmap_liveness_check()` in
`nmap_provider.py`; new `tests/test_nmap_parser.py`; extended `tests/test_nmap_provider.py`.
</objective>
