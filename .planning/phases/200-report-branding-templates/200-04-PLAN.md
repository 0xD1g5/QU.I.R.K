  reads, because existing `SimpleNamespace` fixtures carry no `report` attribute.

  to today — this is asserted, not assumed.

  `templates/report.html.j2` — plan 200-03 owns those in the same wave.

  `writer.py:927` (crit_count for the console table), or `content_model._check_congruence`. Those
