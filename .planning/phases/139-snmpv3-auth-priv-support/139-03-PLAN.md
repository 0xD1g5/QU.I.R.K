<objective>
Wire the v3→v2c→none fallback ladder into BOTH SNMP entry points so SNMPv3 support works through
every code path, not just one. Track WHY a fallback happened so a real credential failure surfaces
as the distinct `v3-failed-fell-back` state (D-03) and a target-side weak-protocol offering surfaces
as the distinct `v3-protocol-mismatch` crypto-hygiene state (D-02) — neither masquerading as an
intentional v2c-only scan nor as each other. Populate the auth/priv protocol columns honestly.

Purpose: This codebase has TWO independent SNMP call sites (Anti-Pattern in RESEARCH.md). Wiring
only one silently breaks v3 through the other — a B-01-class defect. Both must gain the ladder here.
Output: Every SNMP scan attempts v3-then-v2c-then-none and honestly labels the outcome per host,
distinguishing intentional-v2c / auth-failure / protocol-mismatch.
</objective>

    first. Branch on the result:
    (a) SUCCESS (result["snmp_version_used"]=="v3"): set `device.snmp_version` to

    (b) PROTOCOL MISMATCH (result["snmp_v3_failure_kind"]=="protocol-mismatch"): the target offered
        only weaker-than-configured protocols. Set `device.snmp_version = SNMP_MODE_V3_PROTOCOL_MISMATCH`
        (D-02 distinct crypto-hygiene state) and LEAVE `device.snmp_auth_protocol`/`snmp_priv_protocol`
        as None (the configured protocols were rejected — do not claim them). Still fall through to the
        v2c probe for scan continuity, but keep the mismatch label as the recorded snmp_version (the
        crypto-hygiene finding takes precedence over the benign v2c fallback outcome).
    (c) GENERIC v3 FAILURE (null-safe dict, no snmp_version_used, failure_kind None or "auth-failed"):
        fall through to the existing v2c `probe_snmp_target(host, community=..., timeout=timeout)` call
        but set `device.snmp_version = SNMP_MODE_V3_FAILED` (D-03) rather than plain v2c — because v3
        WAS configured and attempted; leave auth/priv protocol columns None.
    When no v3 credential is configured for the host, keep today's behavior and set
    `device.snmp_version = SNMP_MODE_V2C` on a successful v2c result (or leave None/`SNMP_MODE_NONE`

    columns around every new column assignment.
