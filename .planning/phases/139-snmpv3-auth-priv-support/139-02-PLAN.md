<objective>
Add the SNMPv3 USM sibling probe to the scanner: `_async_probe_v3()` alongside the unchanged v2c
`_async_probe()`, a `version`/`v3_credential`-dispatched `probe_snmp_target()`, protocol-name→pysnmp
protocol-object maps so the operator's configured auth/priv choice is actually used, a distinct
protocol-mismatch classification, a re-derived v3 timeout budget, actual-security-level tracking, and
— for the first time in this module — `safe_str` scrubbing on every exception path (SNMPV3-03).

Purpose: The transport core every entry point calls. Honoring the configured protocol (SNMPV3-02),
correct security-level tracking (SNMPV3-02), a distinct weak-protocol-mismatch finding (D-02), and
zero credential leakage (SNMPV3-03) are the load-bearing behaviors; the timeout re-derivation
(SNMPV3-04) prevents spurious USM-discovery timeouts.
Output: A version-dispatched probe returning a uniform dict with new `snmp_version_used` /
`snmp_security_level` / `snmp_v3_failure_kind` keys, using the configured protocol, never leaking
passphrases.
</objective>
