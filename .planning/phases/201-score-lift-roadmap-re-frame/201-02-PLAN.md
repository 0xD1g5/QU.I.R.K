<objective>
Implement `quirk/intelligence/score_lift.py` — the real delta-scoring engine — turning plan 201-01's
RED suite and the firewall's runtime purity legs GREEN.

Purpose: LIFT-01's whole value is that the number is real. The module must produce each lift by
actually re-invoking the production scoring function over a deep-copied, minimally-mutated evidence
dict, and must refuse to produce a number when no honest mutation exists.

Output: one pure intelligence module with two public functions, a slug-keyed delta map covering
exactly the 9 modelable item kinds, and a green Wave 0 suite.

- `quirk/intelligence/scoring.py` is LOCKED (Phase 199 + CONTEXT). Compose evidence dicts OUTSIDE it.
  No new parameter, no seam, no refactor. Same for `quirk/intelligence/roadmap.py` — byte-untouched,
  because `tests/test_intelligence_roadmap.py:52-56` asserts its items' exact 6-key set.
