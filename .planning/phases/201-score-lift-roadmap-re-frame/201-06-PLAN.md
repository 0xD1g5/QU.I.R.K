<objective>
Render score-lift on the dashboard: a per-item badge in the roadmap detail panel, a Projected Score
card, and the print-surface equivalents — exactly as the approved UI-SPEC specifies.

Purpose: LIFT-05's operator-visible half. The UI-SPEC's Copywriting, Color, and Layout & Placement
contracts are binding; this plan implements them rather than reinterpreting them.

Output: extended `roadmap.tsx` and `print.tsx`, a vitest file covering presence/absence, rebuilt and
committed statics, and a human verification of visual placement and tone.

Hard constraints:
- This is an EXTENSION of the existing page, not a redesign. The Cytoscape DAG, the burndown table,
  the phase legend, `PHASE_COLORS`, and all print styling are out of scope and must be unchanged.
- Copy is LOCKED, verbatim: badge `+{N} pts`; card heading `Projected Score`; body
  `Projected score if all items resolved: {N}`; disclaimer
  `Advisory — this projection is a simulation and does not affect the readiness score.`
- Absence renders NOTHING: no `0 pts` badge, no gray placeholder chip, no `N/A`. When
  `projected_score` is null, the whole card is omitted — not a placeholder card.
- No chart, gauge, or comparison-arrow graphic in the Projected Score card. Never conditionally
  mount/unmount a Recharts child anywhere.
- `npm run build && npm run lint && npm run test` in `src/dashboard/` and COMMIT the rebuilt statics —
  FastAPI serves pre-built assets, so an unbuilt change ships nothing.
- Do not touch `types/api.ts` (plan 201-04 owns it) or any backend file.
</objective>
