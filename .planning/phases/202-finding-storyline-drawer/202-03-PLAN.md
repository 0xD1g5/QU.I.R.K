<objective>
Ship the storyline endpoint with its narrative section and its finding-disambiguation join. Theme
attribution is deliberately NOT in this plan — 202-05 adds it in the next wave.

Purpose: `ALGO_IMPACT_MAP` / `REMEDIATION_CATALOG` are Python-only with zero references anywhere
under `quirk/dashboard/`, so the narrative must cross the API (D-02). And D-06 supersedes D-02's
route shape: `FindingItem.id` is `CryptoEndpoint.id`, reused across every finding derived from that
endpoint, so `id` alone would return the wrong finding's storyline silently and plausibly. The
`(id, title)` pair is unique and the client already holds both.

Output: a new `storyline.py` route module, the `FindingStoryline` Pydantic model, a shared
finding-lookup helper extracted from `_derive_findings`, router registration, and the backend test
file.

Hard constraints:
- **Field names and nullability are LOCKED** by 202-02's TS interface. The Pydantic model uses
  `Optional[...] = None` for the nine nullable fields and `finding_id: int`, and the response must
  always serialise every field. No `response_model_exclude_none`, no `exclude_none=True`.
- **No new narrative text, no catalog extension** (D-05). If a finding class has no catalog entry,
  the honest answer is `null` — D-07 accepts this as the common case and the operator has confirmed
  it. Do not add an entry to `ALGO_IMPACT_MAP`, `REMEDIATION_CATALOG`, or `_ALGO_KEYWORDS`.
- **Do NOT call `slug_for_title(finding.title)`.** That function takes *roadmap item* titles
  ("Disable legacy TLS versions"), not finding titles, and returns None for virtually every real
  finding — manufacturing false A1s. Theme resolution goes through the fingerprint join in 202-05.
- **Never `str(exc)` in an HTTP detail**, and never reflect the `title` query parameter into any
  error message. Fixed string only (`connectors.py:38-44` is the precedent).
- `.venv/bin/python`, never bare `python`.
- Plain `git add` + `git commit`; never the gsd `commit --files` wrapper.
- Do NOT invoke any mutating GSD verb, and do not touch `.planning/STATE.md`.
- If any new test calls `write_reports`, it MUST patch `quirk.reports.writer.render_pdf_report` at
  the writer seam or it will fail only under the full suite (TRIAGE-149 ordering pollution — it bit
  Phase 200 and again Phase 201). This plan should not need `write_reports` at all; if you find
  yourself reaching for it, that is a signal the test is reaching past this plan's scope.
