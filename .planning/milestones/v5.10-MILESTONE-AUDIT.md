## Phase 141's Gap-Closure History (notable — worth recording)

Phase 141's initial goal-backward verification scored 3/6 (`gaps_found`): Modbus/TCP fingerprinting
never fired end-to-end due to an unsatisfiable gate condition (`_port == 502` checked against the
wrong endpoint). Two sequential gap-closure rounds were required:

1. **141-08** fixed the *inner* gate — replaced the wrong port check with host-keyed
   `confirmed_open_ports` evidence sourced from the existing port/service scan (no new probe),
   honoring locked decision D-04.
2. A live end-to-end test against the real `otics-modbus`/`otics-bacnet` chaos-lab containers then
   revealed a *second, deeper* bug that 3 rounds of plan-checking on 141-08 alone had not caught:
   `fingerprint_hardware()` was only reachable from inside `run_scan.py`'s `_run_ssh_phase()`,
   gated on `if not ssh_targets: return []` — so a host with zero SSH-classified endpoints (the
   realistic case for a pure OT/ICS device) never reached hardware fingerprinting at all. **141-11**
   fixed this outer gate by routing a supplemental OT-only host set through the existing waterfall,
   outside the SSH guard, with a footprint-safety parameter (`ot_only`) that skips HTTP/SNMP probes
   for OT-only endpoints.
3. **141-09** then re-ran the live validation with proper isolation (confirming zero SSH candidates
   present) and got a clean result: `modbus_probe_state=identified` /
   `bacnet_probe_state=identified` on the same host, dashboard badges rendering correctly (blue
   Modbus, purple BACnet).

This is a useful case study: the live human-verify checkpoint caught a real defect that 3
plan-checker iterations focused on the (correct, but narrower) inner-gate fix did not surface —
because everyone's attention, including the plan-checker's, was on Step 4's internal condition,
not the outer function-call gating one layer up. Retroactive goal-backward verification (run after
the fact for phases 141 and 142, which had shipped without ever getting a formal VERIFICATION.md)
is what surfaced the original gap in the first place.
