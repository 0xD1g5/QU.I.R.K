- **T-182-10 (accepted, user-confirmed):** preserve-unknown-keys means a key the body legitimately
  *removed* now persists until overwritten. **A stale key is recoverable; silently deleted project
  history is not.** Preserving deletion semantics would need an explicit removal list — the schema
  coupling that caused Bug B.
- **A third bug was found during 182-02:** `getMilestoneInfo` in `core.cjs` returns an **invented**
  `v1.0` / `milestone` fallback as a truthy value rather than omitting it. **A merge defends against
  absent values, never fabricated ones** — that is why the overlay alone could not fix the
  no-`ROADMAP.md` reset.
- **Upstream target corrected:** `gsd-build/get-shit-done` is **archived**; the live repo is
  `open-gsd/gsd-core`. The stale target came from `package.json`'s `repository` field — accurate at
  publish time, wrong now. The same frozen-measurement defect the report itself documents.
- **The corruption audit is REPORT-ONLY.** The regex signature is over-broad and cannot distinguish
  corruption from legitimate prose quoting `` `**Field:**``. An automated "repair" would rewrite
  real sentences — the same defect with better intentions.
