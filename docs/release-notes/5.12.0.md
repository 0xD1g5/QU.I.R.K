# QU.I.R.K. 5.12.0 — Release & Verification Integrity

**Released:** 2026-08-14
**Milestone:** v5.12

## What's New

QU.I.R.K. 5.12 closes the gap between "the release pipeline looks fixed" and "the release
pipeline is proven fixed" — every repaired signal from this milestone is verified against a real,
live-tagged run instead of code inspection alone, and the v5.11.0 Windows-asset gap is closed.

- **Release Pipeline Repair + Windows Asset Backfill (Phase 148):** Proved the repaired
  signing self-test with a real run, added a pre-tag dry-run mechanism (RELEASE-02), added a
  scheduled tag-format hygiene guard (RELEASE-03), and closed the root cause of the v5.11.0
  Windows-asset gap (RELEASE-04).
- **Test Suite Triage (Phase 149):** Every one of the ~102 pre-existing failing tests was given
  an explicit, written disposition — fixed, quarantined-xfail, or quarantined-skip — across 9
  clusters in `docs/test-triage-149.md`, including two genuine production bugs fixed in place.
- **Test Suite Green Baseline + CI Gate (Phase 150):** `pytest -q` runs green on a clean
  environment, held by a CI gate (`Linux Full Suite`) that fails the build on any new failure —
  proven on a live PR, not just locally.
- **Phase-Completion Artifact Gates (Phase 151):** A phase can no longer close with a missing
  `VERIFICATION.md`, a stale `VALIDATION.md`, or a missing `docs/UAT-SERIES.md` entry; a
  destructive planning operation can no longer run against an unarchived milestone.
- **Discovery Empirical Closure (Phase 152):** Added the `segmented-network` chaos lab profile,
  empirically resolved the Phase 144 nmap timing artifact (verdict: does not reproduce across 3
  live-fire runs), and flipped the interactive nmap-discovery-first default to Y.
- **Release Tag Cut (Phase 153):** Cut the real `v5.12.0` tag and proved every repaired signal
  from this milestone end-to-end on a live tagged CI run, including the new phase-artifact gates
  applied to the phase that ships them.

## Known Issues

### Windows — Asset Gap Closed

The `v5.11.0` Windows-asset gap (no `quirk-windows-5.11.0.zip`, no GitHub Release object at all,
caused by the signing self-test failing before the Release-creation step) is **closed as of this
release**. `v5.12.0` is the first version with a verified Windows artifact — the repaired
`windows-package` CI job (fixed in commit `1a6effc`, already on `main` since before this tag) ran
a real, live, tagged build and produced a genuine signed artifact, proven end-to-end rather than
inferred from code inspection (RELEASE-01).

No other known issues at this time.

## Upgrade Guidance

release.
