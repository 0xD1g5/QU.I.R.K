## QU.I.R.K. 5.11.0 — PyPI-only release (no Windows asset)

This release is **PyPI-only**. `pip install quirk-scanner==5.11.0` works, but the
`windows-package` job failed at the "CI self-test — ephemeral cert signing round-trip" step —
before the Release-creation step ever ran — so no Windows asset was ever produced or attached to
this tag. Fixed in commit `1a6effc`, already on `main`, but it landed after the `v5.11.0` tag was
pushed. **`v5.12.0` is the first version with a verified Windows artifact.**

**This release intentionally has zero attached assets.** If you were expecting a downloadable
zip and see none listed below, that is correct for this version — see the disposition above.

```bash
pip install quirk-scanner==5.11.0
```

Full disposition and root-cause detail:
https://github.com/0xD1g5/QU.I.R.K/blob/main/docs/release-notes/5.11.0.md
